# بوت استقبال طلبات YK10 Software

بوت تلغرام بياخد من العميل: نوع الخدمة → وصف المشروع → الميزانية، وبعتهن مباشرة لمجموعة تلغرام خاصة عندك.

## 1) أنشئ البوت من BotFather
1. افتح محادثة **@BotFather** بتلغرام.
2. ابعتله `/newbot`.
3. اختار اسم للبوت (مثلاً: YK10 Orders Bot).
4. اختار يوزرنيم ينتهي بـ `bot` (مثلاً: `YK10_orders_bot`).
5. رح يعطيك **توكن** شكله هيك: `123456789:ABCdefGhIJKlmNoPQRstuVwxyZ` — احفظه.

## 2) جيب آي دي المجموعة الخاصة
1. سوي مجموعة تلغرام خاصة (أو استخدم وحدة موجودة).
2. ضيف البوت الجديد فيها كعضو (وأعطيه صلاحية إرسال رسائل على الأقل).
3. ابعت أي رسالة بالمجموعة.
4. افتح بالمتصفح هاد الرابط بعد ما تحط توكنك مكان `<TOKEN>`:
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
5. دور على `"chat":{"id":-100xxxxxxxxxx` — هاد الرقم (فيه سالب بالأول) هو الـ `GROUP_CHAT_ID`.

## 3) جهز المشروع محلياً (للتجربة)
```bash
npm install
cp .env.example .env
```
افتح ملف `.env` وحط فيه التوكن وآي دي المجموعة.

```bash
npm start
```
جرب تحكي مع البوت بتلغرام بـ `/start`.

## 4) تشغيله 24/7 (سيرفر دايم شغال - مجاني)
أسهل طريقة مجانية: **Render.com**

1. ارفع هاد المجلد كـ Repository على GitHub (حساب GitHub يلي عندك: `yazankakaje192-tech`).
2. روح لـ https://render.com وسجل دخول بحساب GitHub.
3. اعمل **New + → Background Worker** (مو Web Service، لأنه البوت ما بيحتاج يفتح بورت).
4. اربطه بالـ Repository يلي رفعته.
5. Build Command: `npm install`
   Start Command: `npm start`
6. من قسم **Environment**، ضيف المتغيرين:
   - `BOT_TOKEN` = التوكن يلي أخدته من BotFather
   - `GROUP_CHAT_ID` = آي دي المجموعة
7. اضغط Deploy، وخلص — البوت رح يضل شغال دايماً بدون ما يحتاج لابتوبك مفتوح.

## ملاحظات
- الأمر `/طلب` أو `/order` بيخلي العميل يبلش طلب جديد بأي وقت.
- `/cancel` بيلغي الطلب الحالي.
- فيك تضيف لاحقاً: حفظ الطلبات بقاعدة بيانات، أو ربطه مباشرة بقناة YK10 Software.
